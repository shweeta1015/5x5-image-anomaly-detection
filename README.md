# 5x5 Image Anomaly Detection

This project detects anomalies in a 5x5 grayscale image using image processing and machine learning techniques.

## Method

5x5 Image → 3x3 Filter → Convolution → ReLU → Feature Extraction → Isolation Forest → Normal/Anomaly

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## ML Algorithm

Isolation Forest is used for anomaly detection.

## CNN Concepts

Convolution and ReLU are used for feature extraction.
